Data mixture by phase

What each phase emphasizes

Each phase weights 200 topic × quality groups. Topic shares below sum over quality buckets; quality shares sum over topics. Phase percentages refer to planned training steps, rounded to mixture-block boundaries. Topic names describe the dominant content in each cluster, using the store’s labels and examples.

  • Start to 25% — Harrier: Software-heavy, led by infrastructure/security (9.3%), performance logs and low-level code (9.0%), and natural-science research (8.8%). General software development/web code contributes 7.9%; history/literature 6.9%; math problems/proofs 4.3%.
  • 25% to roughly 80% — new phase 0: More command-line agent transcripts (1.3% → 6.0%), law/courts (1.1% → 3.6%), and world news (0.8% → 2.7%). Less general software development/web code (7.9% → 4.5%), finance (5.6% → 2.4%), history/literature (6.9% → 3.7%), and math (4.3% → 1.8%). Performance logs and low-level code become the largest cluster at 10.6%.
  • Roughly 80% to finish — new phase 1: More natural-science research (6.9% → 11.3%), alongside performance logs/low-level code (11.4%) and agent transcripts (6.6%). General software development/web code falls again, to 3.1%, and math to 1.4%. The highest classifier-rated quality bucket, Q4, rises from 22.9% to 28.0% of the mixture; it was 22.6% in the initial phase.

Arrows compare each phase with the preceding phase. These are configured weights, not measured token counts or claims that every document matches its cluster’s label. All 40 topic shares and five quality shares.
